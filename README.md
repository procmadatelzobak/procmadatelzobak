### How I work with agents

I treat AI agents as a team, not a tool. I write the architecture, the guardrails, and the brief — the agents do the typing, the deploying, and increasingly the maintenance. A few principles I've landed on:

- **Agents own whole systems, not snippets.** My infrastructure runs itself: agents pick up tickets, write the code, deploy it, and keep the docs honest.
- **Security is a design constraint, not an afterthought.** An autonomous agent that can push to production gets exactly one credential and a blast radius small enough that prompt injection doesn't matter.
- **Sometimes the right answer is *not* to use AI.** (See Babička.)

### Things worth showing

**sinuhetcloud** — A private cloud platform: a mesh of servers across several sites, stitched together with WireGuard and run largely by AI agents. They process GitHub issues, write and deploy code, manage the network, and maintain the documentation. My playground for *how far can you push autonomous ops.* (This README lives there — and was written there.)

**[Maloves](https://maloves.pszczolka.cz)** — A little town of generative AI agents. They chat, trade, hold down jobs, pass laws, and elect a mayor and a judge. Self-hosted on a local LLM — an AI-Town fork that grew its own economy and legal system.

**[ChatMystery](https://game.chatmystery.com)** — An AI detective game: interrogate suspects played by LLMs to crack the case. I designed the architecture and wrote the mysteries; a friend wrote the code. Sold zero copies, still proud of it.

**Babička** — A Minecraft mod meant to be an LLM-driven NPC. The model couldn't handle it, so I rebuilt it as a rule-based system that actually works. My favourite reminder that AI isn't always the answer.

**[furniture-components.com](https://furniture-components.com)** — An AI-friendly product catalog maintained entirely by an autonomous agent that researches parts and publishes pages on its own.

Plus a long tail of smaller experiments — a [relativistic billiards sim](https://relativistic-biliard.pszczolka.cz), an [idle game about breeding sheep](https://incremental-sheep.pszczolka.cz), a [web port of a 4X strategy game](https://20kly.sinuhetcloud.net), a [64k-style JS demo](https://github.com/procmadatelzobak/64k), and a quiz generator my partner actually uses to write pub quizzes for a living.
